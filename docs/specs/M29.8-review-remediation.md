## The eight fixes (findings quoted in the report)

1. **F1 — upload exclusive-create.** Replace the exists-check-then-`"wb"`
   pattern with `open(candidate, "xb")` inside the suffix loop, retrying on
   `FileExistsError` — the filesystem, not a racy check, now enforces
   never-overwrite. Test: a real two-thread same-name upload race (both
   files must exist, distinct names, both contents intact) + the existing
   collision tests stay green.
2. **F2 — REPL keeps the orphan user turn.** `history.append(("user", text))`
   moves to before the route call (web parity: the question enters context
   even when the answer fails; the failure TEXT still never does). Update
   the existing failure test to assert the new parity semantics.
3. **F4 — `is_error` before shape fallback (claude).** Reorder
   `_parse_json_envelope`: a dict envelope with `is_error: true` is a
   provider failure even when `result` is null/absent (error text: `result`
   if str, else `subtype`, else generic). Tests: error envelope without
   `result` → failure, never raw-JSON-as-success.
4. **F14 — empty output → failure (claude, both modes).** Empty stripped
   content (plain mode, JSON `result`, or empty stdout in JSON mode) becomes
   `success=False, error="Claude CLI returned no output."` — hermes parity;
   the router falls through to a provider that answers. Tests for all three
   empty paths.
5. **F5 — switch update-then-prune.** `_switch()` replaces `clear()+update()`
   with `update(new)` then pruning stale keys — `_profile_data` is never
   empty mid-switch and its object identity is preserved (managers hold the
   reference). Test: sentinel key pruned, new keys applied, `id()` unchanged.
6. **F6 — one conversation-id validator.**
   `history.manager.is_valid_conversation_id()` exported; the `/chat`
   handler imports it (inline regex deleted). Test: the same id set agrees
   at both layers.
7. **F7 — portable/history negative test.** Seed a history file, assert no
   `history/` member ever appears in a portable bundle.
8. **F10 — claude.py docstring refresh.** Current CLI reference + M29.5
   model-attribution mention.
