# M29.4 — conversation export — SPEC

**Status: approved (overnight batch). → 2.9.4.** The M29 epic's closer: a
persisted conversation (M29.1) exports as clean Markdown.

## Scope
1. **`GET /history/conversations/{id}/export`** — the conversation rendered
   as Markdown, served `text/markdown` with a
   `Content-Disposition: attachment; filename="<id>.md"` header:
   - `# Conversation <id>` + started-at line;
   - each turn: `## You` or `## Assistant (provider/model)` + the content;
   - failed assistant turns flagged `*(failed)*`;
   - same 400 (bad id) / 404 (missing) semantics as the read endpoint —
     the store's id guard stays the single validation point.
2. **UI**: an "Export" action on each Past-conversations item (opens the
   endpoint URL — the browser downloads the file).
3. Export is **content the user already owns locally** moving to another
   local file — no privacy surface change (still gitignored territory once
   saved wherever the user puts it).

## Tests
Round-trip: chat twice → export → status 200, `text/markdown`, attachment
header, contains both turns + provider heading + `# Conversation`; failed
turn flagged; bad id → 400; missing → 404.
