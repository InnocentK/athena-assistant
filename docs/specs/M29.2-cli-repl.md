# M29.2 — CLI REPL — SPEC

**Status: approved (overnight batch; roadmap wording pre-approved: "`athena`
with no prompt drops into an interactive multi-turn session"). → 2.9.2.**

## Entry semantics (the one behavior change, TTY-gated)

- `athena` with **no prompt on an interactive stdin (TTY)** → REPL.
- `athena` with no prompt and stdin **not** a TTY (scripts, pipes, CI) →
  **unchanged**: usage error, exit 2. Scripts can never hang in a REPL, and
  the existing missing-prompt test keeps passing untouched (pytest's stdin is
  not a TTY).
- One-shot, `ask`, `doctor`, `--list-providers`: all unchanged.

## The loop (`cli/repl.py::run_repl`)

- Prompt `you> ` (stdout prints only answers; prompts/status stay on the
  M25 contract — the input prompt itself goes to stderr so piped stdout
  stays answer-only even in a REPL transcript).
- Per turn, reusing the shared cores (this is why M29.0/29.1 came first):
  `build_turn_messages(history, text)` with the accumulated in-session
  history; spinner + `on_attempt` live status (M27.0); answer → stdout;
  summary/usage lines → stderr (M25/M27.1 helpers); **history records the
  turn only on success** (the M26.10 replay rule, applied to the CLI);
  `record_turn` persists user+assistant turns to the `ConversationStore`
  (M29.1 — the CLI now joins persistent history); `extract_memory` unless
  `--no-memory`.
- Commands: `/exit` | `/quit` (also EOF Ctrl-D) end the session; `/new`
  starts a fresh conversation (clears in-session history + new persisted
  conversation). Ctrl-C mid-input aborts the line, not the session; twice
  (EOF path) exits cleanly. Unknown `/command` → hint on stderr.
- Failure turns: rendered as `Error: …` on stderr (as one-shot does), not
  recorded into the replayed history, but persisted with `success: false`
  meta (same as the web surface).

## Scope guards
- No readline/prompt-toolkit dependency — plain `input()` (arrow-key editing
  comes free where the host readline provides it).
- No streaming (M30), no tab completion, no multi-line editing.

## Tests (`tests/test_repl.py`, all mocked)
- Scripted stdin (monkeypatched `input`): two turns → second `route()` call
  receives 3 messages (history accumulated); `/new` resets to 1; failed turn
  not replayed; turns persisted (2 files after `/new`, correct roles);
  `/exit` → exit 0; EOF → exit 0; non-TTY bare invocation still exits 2
  (existing test in `test_cli.py` — unchanged).
