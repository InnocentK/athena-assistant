# M26.19 — Ruff (lint/format) + dependency pinning — SPEC

**Status: specced, awaiting go-ahead. Do NOT implement without explicit approval.**

## Why

The project has no automated correctness gate besides the test suite. Ruff would
have instantly flagged the ~400 unused imports the M26.18 split left behind
(cleaned by hand) and catches undefined names, unused variables, and import
mistakes a passing suite cannot see. Dependencies are also unpinned, which is a
reproducibility hole: M26.12 relies on `caldav` 3.x forwarding `timeout=`, M26.15
on `defusedxml`'s entity rejection — a future major bump could break the app in a
fresh environment with no signal to a weak agent.

## Current violation inventory (measured, ruff default rules, `.venv` excluded)

**26 total, 22 auto-fixable.** By rule:

- `F401` unused-import ×20 (incl. a few still in `app/routers/*` and
  `carddav_integration/client.py`)
- `F841` unused-variable ×2 — `dav_io/ics_io.py:495` (`in_component`),
  `tests/test_dav_io.py:670` (`tmp_project`)
- `F811` redefined-while-unused ×1 — `tests/test_ops_hardening.py:436`
  (`MagicMock` re-imported)
- `F821` undefined-name ×1 — `main.py` `_safe_export_path(...) -> Path`: `Path`
  is referenced only in the return annotation. Under `from __future__ import
  annotations` the annotation is a string and never evaluated, so **nothing is
  broken at runtime** — but it's an incorrect reference. Fix: add
  `from pathlib import Path` to `main.py`. (Pre-existing; not introduced by the
  split.)
- `E401` multiple-imports-on-one-line ×1, `E741` ambiguous-variable-name ×1
  (`l`) — cosmetic.

None are behaviour bugs today, but each is exactly the class ruff should keep out
going forward.

## Scope

1. **Add ruff as a dev dependency** (`requirements.txt` Dev/test section) and a
   `ruff.toml` (or `[tool.ruff]` in `pyproject.toml` — prefer `pyproject.toml` to
   keep config centralized).
   - `target-version = "py310"` (project's floor), `line-length = 100`.
   - `exclude = [".venv", "__pycache__", "logs", "audit", "data"]`.
   - **Correctness-strict, style-lenient to start** (avoid a 2,000-line reformat
     masquerading as "add a linter"). Initial `select`:
     `["E4","E7","E9","F","B","I"]` — pyflakes (F: unused/undefined), a subset of
     pycodestyle errors, bugbear (B: real footguns), and isort (I: import order,
     autofixable). Explicitly **do not** enable the whole `E`/`W`/`D`/`ANN`
     families yet.
   - `[tool.ruff.lint.per-file-ignores]`: tests may keep `F401`/`F811` only where
     a fixture import is intentional — but prefer fixing over ignoring; add
     ignores only if a real false-positive appears.
2. **Fix the 26 current violations.** Run `ruff check --fix` for the 22
   autofixable, then hand-fix the 4: add `Path` import to `main.py`; delete the
   two dead locals; dedupe the `MagicMock` import; rename/relabel the `E741`
   variable. Re-run the full suite after — must stay green (fixing unused
   imports/vars is behaviour-neutral, but verify).
3. **`ruff format`** is NOT run in this milestone (it would reformat everything).
   Leave a note in the spec/CHANGELOG that formatting is a possible future
   follow-up; adopting the linter first is the low-risk step.
4. **Pin runtime dependencies.** Rewrite `requirements.txt` with compatible-release
   pins for the currently-installed, tested versions (captured 2026-07-14):
   `fastapi==0.139.0`, `uvicorn[standard]==0.46.0`, `pyyaml==6.0.3`,
   `python-dotenv==1.2.2`, `pydantic==2.13.3`, `openai==2.45.0`, `jinja2==3.1.6`,
   `python-multipart==0.0.26`, `caldav==3.2.1`, `vobject==0.9.9`,
   `requests==2.33.1`, `defusedxml==0.7.1`; dev: `pytest==9.1.1`, `httpx==0.28.1`,
   `pytest-mock==3.15.1`, `ruff==<installed>`.
   - Use `==` for a reproducible baseline (this is a single-user app, not a
     library — exact pins are appropriate and easiest for a weak agent to reason
     about). Document that bumping a pin is a deliberate, tested act.
   - Sanity: `pip install -r requirements.txt` in a fresh venv + full suite green.
5. **Taskfile:** add a `lint` task (`ruff check .`) and `lint:fix`
   (`ruff check --fix .`). Wire `lint` into the `SessionStart` hook script
   (`scripts/session-start-check.sh`) as a fast pre-suite step (ruff is
   sub-second) so a fresh agent sees lint status too. Update `docs/VALIDATION.md`
   / `TESTING.md` to mention `task lint`.
6. **Version:** this is tooling + a handful of dead-code deletions — bump to
   **2.6.19** (the dead-local removals are code changes). Update `core/version.py`
   only (single source). CHANGELOG entry; INVARIANTS note ("ruff correctness
   rules must pass — `task lint`; config in pyproject `[tool.ruff]`").
